# Cloud Computing Reflection

Cloud computing is part of my daily life even if I do not always realize it. I regularly use Google Drive, Messenger, and Canva for school, communication, and personal tasks.

Google Drive is an example of Software as a Service (SaaS) because I can store and access files online using a web browser without installing special software. It uses the Public Cloud deployment model since Google's cloud services are available to millions of users over the internet.

Messenger is also a SaaS application because it allows users to communicate through messages, voice calls, and video calls using cloud-based services. It is also classified under the Public Cloud because it is accessible to anyone with an account.

Canva is another SaaS application. It provides online graphic design tools that run entirely through the internet. Canva stores projects online, making it easy to continue working on different devices. Like the others, it uses the Public Cloud deployment model.

Git and GitHub are important tools for cloud computing projects because they help manage changes in files and code. Version control keeps track of every modification, allowing developers to return to previous versions if mistakes happen. This reduces the risk of losing important work.

GitHub also makes teamwork easier because multiple people can work on the same project without overwriting each other's changes. Team members can review updates, discuss improvements, and merge changes safely. In cloud infrastructure projects where many configuration files are involved, version control helps prevent errors and keeps the project organized.

Overall, this activity helped me understand that cloud computing is already part of my everyday life. Learning Git and GitHub will also help me become more organized and prepared for future cloud-based projects and professional software development.
