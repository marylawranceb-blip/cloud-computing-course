# Laboratory 03 – Multi-Cloud Explorer
Create Laboratory 03
This laboratory activity explores and compares Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). It also includes Linux investigation, cloud service comparison, business recommendations, and a reflection on cloud computing.

## Linux Playground Activity

The Linux Playground was used to explore basic Linux commands.

Commands used:
- `pwd` – displays the current directory
- `ls` – lists files and directories
- `whoami` – displays the current user
- `uname -a` – displays Linux system information
- `df -h` – displays disk space information

The activity helped demonstrate basic Linux system and file management commands.
