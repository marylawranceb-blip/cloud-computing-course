# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform from Microsoft that provides services for computing, storage, networking, databases, security, analytics, and application development.

## Global Infrastructure

Azure provides cloud infrastructure through geographic areas containing Azure Regions. Azure also provides Availability Zones in supported regions. These infrastructure options help organizations place applications and data closer to users and improve resilience.

## Cloud Management Console

The Azure portal is a web-based management console used to create, manage, configure, and monitor Azure resources. It provides a graphical interface where users can access services, create resources, manage subscriptions, and monitor cloud environments.

## Four Core Services

1. Azure Virtual Machines – Provides virtual machines for running applications and operating systems.
2. Azure Blob Storage – Provides object storage for unstructured data.
3. Azure Virtual Network – Provides networking for Azure resources.
4. Microsoft Entra ID – Provides identity and access management.

## Three Advantages

1. Azure integrates well with Microsoft products and technologies.
2. Azure provides a broad range of enterprise cloud services.
3. Azure supports hybrid cloud environments and organizations with existing Microsoft infrastructure.

## Typical Enterprise Use Cases

Azure is commonly used for enterprise applications, Windows Server workloads, Microsoft 365-related environments, databases, web applications, analytics, backup, and hybrid cloud deployments.
